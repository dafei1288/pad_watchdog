# 需求：Pad 使用时间管控（家长侧统计工具）

## 定位
家长使用的 Web 应用，只做**记录与统计**，不做锁屏/守护，不装在孩子的 Pad 上。

## 核心规则
- 以**自然周**（周一 00:00 ~ 周日 24:00）为周期，设置每周观看总时长上限（默认 150 分钟）。
- 单次连续观看时长上限（默认 90 分钟）。
- 可从当前时间起预约观看时段，形成观看日历。
- 统计观看时间，提供统计图表。
- 本周可超用，但超用部分从下周额度抵扣，累计透支上限 60 分钟。
- 支持**多个孩子**，各自独立的额度与记录。
- 额度、单次上限、透支上限等均为**可配置**项。

## 已确认的决策
| 项 | 决策 |
|---|---|
| 应用形态 | Web 应用：Express 后端 + Vue 前端 |
| 存储 | SQLite 文件（`node:sqlite`，数据在 `data/pad-watchdog.db`） |
| 计时方式 | 实时计时器（可设本次计划时长，倒计时到点自动结算）+ 手动补录 |
| 到时提醒 | 计划时长到点：循环响铃 + 标题闪烁 + 弹层提醒，点“知道了”停止；会话仍自动结算 |
| 锁屏 | 不做。Web 页面无锁屏能力，强制锁屏需用系统家长控制（见调研结论） |
| 页面 | 查看 / 日历 / 统计对比 / 配置 四个独立页面 |
| 周边界 | 自然周 |
| 预约与额度 | 预约只做日历展示与提醒，不预扣额度；实际使用才计时 |
| 超用 | 显式借用，从下周额度抵扣，累计透支 ≤ 60 分钟 |
| 多孩子 | 每孩子独立配置、独立账本，日历与图表按颜色对比 |
